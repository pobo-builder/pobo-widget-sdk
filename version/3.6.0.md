# 3.6.0

## New: scroll video
- `pb-scroll-video` plugin styles (`__poster`, `__canvas`) in both generic and legacy builds; the frames are drawn by the pobo-plugin `ScrollVideo` widget
- 14 widgets: `rc-scroll-video-full`, `-text-right`, `-text-left`, `-intro`, `-cta`, `-benefits`, `-pair`, `-portrait`, `-overlay`, `-parameter`, `-steps`, `-product`, `-grid`, `-hero`
- `__video` is the `pb-scroll-video` wrapper itself (no `__media` box around it); text areas are single rich-text blocks (heading and paragraph inside `__text`, `__head`, `__caption`, `__item`, `__header`), a `__button > __link` sits next to `__text` in `-cta` and `-hero`; headings are styled by typography, the widget variables cover layout only (`--pobo-scroll-video-<name>-video-*` on the video, `--pobo-scroll-video-<name>-box-*` on the text box, mobile overrides in `mobile-variable`)
- Files live in `src/generic/scroll-video/` (legacy copies in `src/rc-scroll-*.scss`)

## New: scroll track (pinned scrollytelling)
- `pb-scroll-track` plugin styles (`plugin/scroll-track`): `--pinned` keeps `__pin` sticky for `--pobo-scroll-step-count` viewports and switches `__step` chapters via `is-active` / `is-passed`; `--static` is the fallback when an ancestor clips overflow; `pb-scroll-reveal` is optional inside a track; `prefers-reduced-motion` shows everything
- 3 story widgets: `rc-scroll-story-side` (video left, `__step > __number + __text` chapters right), `rc-scroll-story-overlay` (full-bleed video, `__step > __text` chapters bottom-left), `rc-scroll-story-hero` (full-bleed video, centered `__text`, last step with a `__button > __link` using `--pobo-btn-*`); without the pinned class they render stacked (editor, catalogue preview, static fallback)
- `--pobo-scroll-track-*`, `--pobo-scroll-reveal-*` and `--pobo-scroll-story-*` variables with mobile overrides
- Pinned sections are full-bleed: `pb-scroll-track--pinned` breaks out of the description column to the viewport width (`--pobo-scroll-track-bleed-width`, výchozí `100vw`; the plugin writes the real viewport width without scrollbar into `--pobo-scroll-viewport-width`), the static fallback stays in the column; `--pobo-scroll-track-bleed-width` (`100vw`) and )`) turn it off when set to `100%` / `0`. Inside the bleed the chapters sit in a centred content box (`--pobo-scroll-story-<name>-content-max-width` 1200px, `--pobo-scroll-story-<name>-content-padding` 40px, mobile 20px); `-side` goes two-column (video 58 % / chapters 42 %) from `lg`, stacked below, with `--pobo-scroll-story-side-pinned-video-max-height` capping the poster in the two-column layout
